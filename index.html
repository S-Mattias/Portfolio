Assignment 1

1. Inspiration

I selected the "Dimension" aesthetic from html5up.net as my primary inspiration. I was drawn to its "Single Page Application" feel, which keeps everything clean and contained. However, I decided not to use their code directly, but rather to recreate the layout myself to better understand CSS Flexbox. I wanted to personalize it by using a Black Hole video loop that I created myself as the background, giving the portfolio a sci-fi atmosphere compared to standard static images.

2. Process & Technical Implementation

Coding: I built the site using HTML5 and CSS3. I utilized CSS Flexbox to center the content cards. I used Gemini AI to help explain how to position the text overlays so they wouldn't cover the center of the black hole.

Media Processing: The original black hole video file was very large. To ensure the website loads reasonably fast, I converted the file to MP4 format and compressed it. I also used a CSS overlay to darken the video slightly so the white text remains readable.

Figure 1: HTML Video Implementation

3. Github Deployment

To host the website, I uploaded all my files to github by dragging my files from my folder to github. After uploading I went into settings, then pages, and then from branch I put in main instead of none.

Figure 2: Uploading via Git Bash

4. Thoughts

While I have some experience with websites, building a portfolio from scratch using raw HTML/CSS was a valuable refresher. The biggest challenge was balancing the high-quality video background with page load performance.
