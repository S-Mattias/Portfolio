Assignment 1

Documentation

Inspiration: I chose the html template "Dimension" from https://html5up.net/ as an inspiration for my portfolio website, as it looked very clean and nice. I wanted to use a black hole that I had created a long time ago as the background as a starter for this portfolio. The black hole takes a bit to load in, however in my opinion it is quite nice to have in the background.

Process: I started off looking for inspiration on html5up and I found Dimension which looked quite unique and clean to me. I used it as inspiration as I built my portfolio using HTML5 and CSS3, utilizing Flexbox for the layout to ensure everything stays centered. I got the help of Gemini to help me with some aspects such as the buttons and inserting the video in the background. I had to look up for tutorials on how to upload this website on github.

Thoughts: Overall I didn't think this project was all too dificult as I have made a website before for my startup, but overall this was a nice experience.
